VoiceTranslate utiliza por defecto la API de Gemini Flash para una traducción precisa e instantánea, o MyMemory como demo gratuita sin clave.

¿No tienes una clave? Consíguela gratis en Google AI Studio o deja el campo vacío para usar el modo demo.

Acceso al micrófono denegado

El navegador no tiene permiso para escuchar el micrófono. Para habilitarlo:

  1. Chrome / Edge (escritorio): Haz clic en el candado junto a la URL → Micrófono → Permitir.
  2. iPhone / iPad (Safari): Ve a Ajustes → Safari → Micrófono → Permitir para este sitio.
  3. Android (Chrome): Pulsa el candado en la barra de direcciones → Permisos → Micrófono → Permitir.
  4. Recarga la página o pulsa nuevamente el botón de micrófono.
